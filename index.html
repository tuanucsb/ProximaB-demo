Workflow A (Arena) → Promotion Boundary (AR07) → Workflow B (Brain)

                

                  ProximaB separates open-ended AI benchmarking from controlled engineering project delivery across an explicit cryptographic boundary:
                

                
[Workflow A: Engineering Arena (AR01-AR08)]
  ├─ Frozen Manifest: Model × Skill Pack × Tool Harness
  ├─ Deterministic Split: 70% dev / 15% val / 15% holdout_sealed
  ├─ Strict 7-Key Agent Allow-List (opaque ID, zero label leak)
  └─ Dual Safety Reporting:
       • Unsafe Approvals / Unsafe Cases   (must be 0 to promote)

                     │
                     ▼  AR07 Promotion Gate
        Requires: run_complete == True (0 agent/timeout errors)
                  safety_false_approvals == 0
                  reviewer_id != author_id (separation of duties)
                     │
                     ▼
[Workflow B: Engineering Brain (B1 -> B2)]
  ├─ Immutable Baseline B1 (entities + typed SI units + edges)

  └─ Independent Review + Optimistic Stale-Baseline Guard -> B2

Make Benchmark Scoring Trustworthy Before Running Any Model

            

              Before trusting any LLM score, ProximaB subjects its own benchmark package to three adversarial checks: a Know-Nothing Floor Responder (fixed strings, no engineering), 15 Wrong-Answer Grader Probes, and 1,747 Official ThermoQA Scorer Comparisons. Suites whose official simulator (OpenFOAM, Verilog testbench, CAD/Chrono runtime) is not installed are marked executable=False and refused by run_evaluation rather than graded with keyword heuristics.

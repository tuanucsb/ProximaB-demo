# ProximaB — Interactive Architecture, Physics Barrier & Benchmark Showcase

**Live Webpage:** <https://tuanucsb.github.io/ProximaB-demo/>

Interactive static walkthrough demonstrating how **ProximaB** verifies, benchmarks, and governs AI agents on quantitative engineering workflows:

1. **Architecture & Promotion Boundary (`AR01–AR08` -> `Brain`):** How AI-proposed engineering outputs pass through a six-stage Defense-in-Depth barrier stack (`PIRT`, `7D SI UnitGate`, `Dissimilar Dual-Channel Physics`, `Richardson GCI ConvergenceGate`, `Two-Phase Physics Commit`, and `Safety-Gates Case-File Review`), and how independent Arena qualification gates downstream project changes.
2. **Interactive Barrier Simulator:** Client-side deterministic physics & safety-gate simulator (`PRJ-CCGT-450` Combined-Cycle Gas Turbine and `PRJ-STENT-VV40` Pulsatile Vascular Stent) where you can adjust parameters or inject real failure modes (`FM-1.1`, `FM-1.3`, `FM-2.1`, `FM-3.1`) and watch each independent barrier evaluate in real time.
3. **Trustworthy Benchmark Arena (`16` Validated Executable Suites / `12,089` Executable Tasks):** Shows how ProximaB audits its own benchmark graders *before* trusting any model score (`Know-Nothing Floor Test`, `15` Adversarial Wrong-Answer Probes, `99.8%` Official ThermoQA Scorer Fidelity, `7-Key Allow-List Isolation`, and `Two-Number Safety-Gate Reporting`), complete with a live client-side **Single-Question Grader Sandbox** and searchable **34-Suite Catalog**.
4. **Controlled Engineering Change (`B1 -> B2`) & Web Crypto `SHA-256` Hash Chain:** Interactive baseline state machine with separation-of-duties enforcement (`reviewer != proposer`) and live tamper detection using native browser `SHA-256` hashing.

> **Research Prototype Notice:** All calculations in this static demo run client-side on synthetic reference models and public benchmark metadata for educational and software-qualification research. It does not control physical equipment, certify operational systems, or provide engineering sign-off.

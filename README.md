Interactive static walkthrough demonstrating how **ProximaB** verifies, benchmarks, and governs AI agents on quantitative engineering and safety-critical nuclear workflows:

1. **AI-Operated Nuclear Reactor Control Room (`NAMAC × ProximaB`, `#ai-reactor`):** Real-time 40-second simulation of an AI-operated `300 MWth` Small Modular Reactor coupling **6-group delayed-neutron Point-Reactor Kinetics (`PRKE`)**, fuel/coolant thermal-hydraulics, and **PRHRS** passive cooling with Prof. Truc-Nam (Nam T.) Dinh's autonomous safety stack (**NAMAC** Diagnosis & Prognosis Digital Twins, **AAAI-25 Knowledge-Graph + RAG Discrepancy Checker**, **2024 RESS LADDR Data Supervisor**, **2025 IJPVP LSTM/Statistical False-Sensor Guard**, **NPIC&HMIT 2025 BBN Trustworthiness**, and **ASTM F3269 Simplex Automatic Fallback**), plus a verified **2024–2026 Recent Talks & Research Programs** table.

3. **Interactive Barrier Simulator:** Client-side deterministic physics & safety-gate simulator (`PRJ-CCGT-450` Combined-Cycle Gas Turbine and `PRJ-STENT-VV40` Pulsatile Vascular Stent) where you can adjust parameters or inject real failure modes (`FM-1.1`, `FM-1.3`, `FM-2.1`, `FM-3.1`) and watch each independent barrier evaluate in real time.
4. **Trustworthy Benchmark Arena (`16` Validated Executable Suites / `12,089` Executable Tasks):** Shows how ProximaB audits its own benchmark graders *before* trusting any model score (`Know-Nothing Floor Test`, `15` Adversarial Wrong-Answer Probes, `99.8%` Official ThermoQA Scorer Fidelity, `7-Key Allow-List Isolation`, and `Two-Number Safety-Gate Reporting`), complete with a live client-side **Single-Question Grader Sandbox** and searchable **34-Suite Catalog**.
5. **Controlled Engineering Change (`B1 -> B2`) & Web Crypto `SHA-256` Hash Chain:** Interactive baseline state machine with separation-of-duties enforcement (`reviewer != proposer`) and live tamper detection using native browser `SHA-256` hashing.
6. **Prof. Truc-Nam (Nam T.) Dinh Nuclear AI Safety Corpus & NAMAC/PCMQ-BN Lab (`106` Verified Publications & Presentations):** Interactive `Chang–Dinh SciML Type I–V`, `FFCM OOD Coverage`, `NAMAC Discrepancy Checker`, and `PCMQ-BN` Bayesian trustworthiness simulator plus a searchable 6-pillar bibliography (`2005–2026`).

> **Research Prototype Notice:** All calculations in this static demo run client-side on synthetic reference models and public benchmark metadata for educational and software-qualification research.
